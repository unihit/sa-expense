# SA Expense Web

브라우저에서 동작하는 개인경비 도구. 정적 HTML/JS이며 서버에 영수증·경비를 저장하지 않습니다.

- IndexedDB: 내역·이미지·설정 저장
- Tesseract.js 7 + Tesseract fast 한국어·영어 모델: 같은 출처에서 자료를 내려받아 로컬 인식
- JSZip + 원본 OOXML 셀 갱신: 회사 XLSX 양식의 기존 구조·서식·수식 보존
- Canvas: 번호·일자와 원본 이미지로 JPEG 출력, 여러 페이지는 ZIP
- PDF.js: 업로드 PDF를 브라우저에서 페이지 이미지로 변환
- 백업: 전체 내역·이미지·설정이 포함된 JSON, 복원은 ID 기준 병합

입력한 내역만 표시하고 빈 행과 미사용 자차 영역은 숨깁니다. 35건을 초과하면 행을 추가하고 합계·인쇄영역을 조정하여 한 엑셀로 출력합니다. 날짜가 없는 요일은 문자열 빈 캐시를 사용해 토요일 표시를 방지합니다. 일반경비만 지원하며 자차 거리정산·환불은 지원하지 않습니다.

실행/배포: dist 디렉터리 정적 호스팅. 별도 API 키나 서버 실행은 필요 없습니다. 모든 원본 라이브러리와 OCR 자료는 vendor에 보관되어 있으며 개인 영수증·초기 데이터는 소스에 포함하지 않습니다. template.xlsx는 공개용 빈 양식입니다. 영수증 이미지, 작성 예시, 사내 지원한도, 댓글, 프린터 설정과 작성자 정보는 제거했습니다.

검증: npm test로 OCR 로직과 엑셀 출력의 회귀 테스트를 실행할 수 있습니다.

가독성: Noto Sans CJK KR 서브셋 웹폰트, 본문·입력·표 크기와 글자 대비 개선. OFL 전문은 vendor/fonts에 포함합니다.

OCR: 결제·승인 > 합계 > 요금 순으로 후보를 평가하고 세금·잔액·누적·번호는 제외합니다. 통화 생략·줄바꿈·전각 및 숫자 안 O/I 혼동을 지원하며 동률 후보가 다르면 빈칸으로 안내합니다. 회색조 1차 후 누락/낮은 신뢰도일 때 이진화·다른 행 분할로 재시도합니다. 단일 승하차는 오른쪽 금액 영역을 별도로 재인식합니다.

## 테마 복구

파란색과 초록색 테마 원본은 theme-snapshots/에 보관합니다. 두 테마 모두 로고 정렬 수정과 짧은 백업 파일명을 유지합니다.

- 초록색 복구: npm run theme:green
- 파란색 복구: npm run theme:blue

명령은 색상 스타일·로고와 캐시 버전만 로컬에서 변경합니다. 경비 데이터·신청 한도·다운로드 로직은 변경하지 않습니다.
화면을 확인한 후 dist/app.css, dist/brand-mark.svg, dist/index.html을 커밋하고 main에 푸시하면 Pages에 배포됩니다.
